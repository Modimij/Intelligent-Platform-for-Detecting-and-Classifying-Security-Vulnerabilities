## Core Technologies
* **Programming Language:** Python
* **Frameworks/Libraries:** Scikit-learn, Pandas, NumPy (عدليها حسب ما استخدمتيه)
* **Field:** Artificial Intelligence & Cybersecurity

## Key Features
* **Automated Detection:** Scans for potential security flaws within software systems.
* **AI-Driven Classification:** Categorizes vulnerabilities based on severity level using ML algorithms.
* **Remediation Insights:** Provides suggestions for fixing identified security issues.

## About the Project
This platform was developed as my Bachelor's graduation project to bridge the gap between AI and Cybersecurity, aiming to make security audits faster and more accurate.
